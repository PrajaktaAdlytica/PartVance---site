# PartVance Brand Assets

## Files

- `partvance-logo.svg` — horizontal website/header logo.
- `partvance-mark.svg` — standalone brand mark for app icons, social avatars, and product UI.
- `favicon.svg` — SVG favicon source.
- `favicon-16.png`, `favicon-32.png`, `favicon-48.png` — PNG favicon sizes.
- `apple-touch-icon.png` — 180px iOS home-screen icon.

## Logo Concept

The mark combines three ideas:

- A hexagonal spare-part/nut shape for industrial components and MRO inventory.
- A rising signal path for forecasting and predictive decision-making.
- Three connected colored nodes for Forecast, Risk, and Suppliers.

It represents spare parts intelligence moving industrial teams from reactive maintenance to predictive decisions.
